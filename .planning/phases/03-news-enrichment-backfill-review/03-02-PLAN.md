## Phase Goal

**As** Jason, the analyst behind a public portfolio app, **I want to** run one job that turns every detected SPY episode since 1993 into a sourced, schema-validated news explanation (or an honest `unexplained` / `needs_review`), within a hard $25 budget, and then review and override the results locally, **so that** the Event Explorer in Phase 4 can show explanations that are traceable and never presented as fact without a dated source.

This slice makes the job real: `--provider claude` calls Claude with server-side web search and structured output, cross-validates every cited source against the tool's own search results, stores a sanitized raw response, logs spend against verified prices and refuses to exceed the budget. All of it is tested offline with a fake client; no money is spent in this plan.

<threat_model>
## Trust Boundaries

| Boundary | Description |
|----------|-------------|
| web pages -> Claude context -> model JSON | Search results are untrusted third-party content (prompt injection) |
| Anthropic API response -> data/events.json | Response body becomes public committed data |
| env (ANTHROPIC_API_KEY) -> job process | Secret enters the process; must not leave via files, logs, errors |
| job -> paid API | Every call spends money against a $25 cap |

## STRIDE Threat Register

| Threat ID | Category | Component | Disposition | Mitigation Plan |
|-----------|----------|-----------|-------------|-----------------|
| T-03-06 | Tampering | prompt injection via search results | mitigate | Sources kept only if URL was returned by the tool and tool page_age is in-window (filter_sources_in_window); title/publisher/date never from model; status rules downgrade-only; system prompt marks page content untrusted; scheduled flag from Phase 2 catalyst, not the model |
| T-03-07 | Information Disclosure | raw_response storage | mitigate | Only response.model_dump() bodies stored, never request/headers; sanitize_raw_response strips encrypted_content/encrypted_index/cited_text; sentinel-key tests over events file, ledger, stdout and stderr |
| T-03-08 | Information Disclosure | SDK exceptions | mitigate | All API errors re-raised as ValueError with episode_id and exception type name only, `from None` |
| T-03-09 | Denial of Service (budget) | jobs/enrich_events.py | mitigate | max_uses per request decremented across pause_turn continuations; news_max_continuations; news_max_episodes_per_run; budget guard before every call using logged ledger total + reserve vs news_budget_usd |
| T-03-10 | Spoofing (model identity) | preflight | mitigate | models.retrieve(model) before any spend; model ID recorded per record and per ledger run |
| T-03-11 | Repudiation | spend accounting | mitigate | Ledger entry rewritten after every episode with tokens, searches and cost from verified config prices |
| T-03-SC | Tampering | package installs | accept | No new packages beyond 03-01's audited set |
</threat_model>
