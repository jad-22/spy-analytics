<objective>
## Phase Goal

**As** Jason, the analyst behind a public portfolio app, **I want to** run one job that turns every detected SPY episode since 1993 into a sourced, schema-validated news explanation (or an honest `unexplained` / `needs_review`), within a hard $25 budget, and then review and override the results locally, **so that** the Event Explorer in Phase 4 can show explanations that are traceable and never presented as fact without a dated source.

This plan delivers the first end-to-end slice, offline: `jobs/enrich_events.py` reads the committed `data/episodes.parquet`, asks a `NewsProvider` (here the deterministic `NullProvider`) to explain each pending episode, validates the result with pydantic, enforces the status rules in code, and atomically writes an events JSON file. Re-runs are incremental. The real Claude provider (03-02) plugs into this exact contract.

Purpose: NEWS-01 (interface + NullProvider), NEWS-02, NEWS-04, NEWS-05 record shape, NEWS-06, and the NEWS-07 config surface, honoring D-01 (verified model IDs and prices in config) and D-02 (pure logic in core/news/, no network).
Output: core/news/{schema,base,null,cost}.py, News block in core/config.py, JSON helpers in core/storage.py, jobs/enrich_events.py, tests.
</objective>
