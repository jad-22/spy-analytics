<objective>
Walking skeleton for SPY Market Lens: the thinnest end-to-end stack. A visitor opens the
Streamlit app and sees the Overview page plot SPY prices from a committed 1993+ snapshot. The
offline job wrote that snapshot, and the page reads it through one cached storage module with
no runtime network calls.

Phase goal (MVP user story):

**As a** portfolio visitor, **I want to** open the public SPY Market Lens app and see SPY price
context and an honest MA backtest, **so that** I can judge the analysis knowing every number
comes from committed data with no look-ahead.

Purpose: proves framework, routing, data read, data write and the UI interaction together
before any feature depth is added. See SKELETON.md in this phase directory for the
architectural decisions later plans build on.
Output: app/ scaffold, core/storage.py, jobs/refresh_prices.py, 1993+ data/prices.parquet,
data/meta.json, end-to-end AppTest tests.
