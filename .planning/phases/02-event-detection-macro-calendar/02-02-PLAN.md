<objective>
## Phase Goal

**As an** analyst preparing the news backfill (and the downstream Phase 3/4 jobs that read `data/`), **I want to** run one detector job that writes a deterministic, replay-stable list of every major SPY shock, gap, drawdown and rally episode since 1993, each tagged with any scheduled US macro release in its window, **so that** news enrichment works on a stable, low-hundreds set of episodes and can tell scheduled catalysts from surprises.

This slice makes the committed episode list safe to enrich: each episode is marked `closed` or `open`, and a replay test proves closed episodes never change when data is appended. Phase 3's irreversible LLM spend is gated on this test (STATE.md roadmap decision).

Purpose: DET-05. Episode IDs are pure functions of data inside a closed window (RESEARCH Pattern 2); this plan makes "closed" precise and tested.
Output: closure logic in core/events.py, tests/test_episode_replay.py, regenerated data/episodes.parquet.
</objective>
