2) core/events.py — new pure module. Docstring states: pure, no Streamlit, no network, must not import core.data or core.storage; caller passes a price frame on the basis it wants (the job passes total return); all thresholds arrive via a `Settings` argument; trading-day distances use integer positions in the DatetimeIndex, never pd.Timedelta. Imports only numpy, pandas, dataclasses, typing, and `from core.config import Settings`. Contents:
- `@dataclass(frozen=True) class Leg`: kind (str), start_pos (int), end_pos (int), move (float), recovery_pos (int | None).
- `log_returns(close) -> pd.Series` = np.log(close / close.shift(1)).
- `shock_zscores(close, sigma_window) -> pd.Series`: log return divided by `log_returns.rolling(sigma_window, min_periods=sigma_window).std().shift(1)` (lagged one day, DET-01).
- `shock_days(close, sigma_window, z_threshold) -> pd.DatetimeIndex`: dates where |z| > z_threshold.
- `gap_days(open_, close, threshold) -> pd.DatetimeIndex`: dates where |open/close.shift(1) - 1| > threshold (DET-02).
- `drawdown_legs(close, threshold) -> list[Leg]`: single causal pass in the drawdown_table style tracking all-time running peak; when price makes a new high (>= peak) and the episode since the peak had trough/peak - 1 <= -threshold, emit Leg("drawdown", peak_pos, trough_pos, trough/peak - 1, recovery_pos=current pos); at the end of data, if currently below peak and depth so far <= -threshold, emit with recovery_pos=None. Trough = earliest position of the minimum close since the peak.
- `rally_legs(close, threshold, window) -> list[Leg]`: for each position i, j = earliest argmin of close over positions [max(0, i-window), i]; if close[i]/close[j] - 1 >= threshold record candidate interval (j, i). Sort-and-sweep merge candidate intervals that overlap or touch (next start <= current end). For each merged [s, e]: trough = earliest argmin of close[s..e], peak = earliest argmax of close[trough..e]; emit Leg("rally", trough, peak, close[peak]/close[trough] - 1, None).
- `cluster_legs(legs, merge_window_days) -> list[list[Leg]]`: per D-01 steepest-leg merge — sort legs by (start_pos, end_pos, kind) and sweep: a leg joins the current cluster when leg.start_pos - cluster_end <= merge_window_days; cluster_end = max(cluster_end, leg.end_pos). Shock and gap days enter as single-day Legs (start_pos == end_pos, move = that day's log return, recovery_pos None). Never use recovery_pos for clustering (D-01).
- `detect(prices, settings) -> pd.DataFrame` with module constant `EPISODE_COLUMNS` (order from the interfaces block). Per cluster: start_pos = min start, end_pos = max end; trigger = first kind in settings.trigger_precedence present in the cluster (Pitfall 4 — never set iteration order); triggers = ",".join(sorted(kinds)); anchor = position in [start_pos, end_pos] with the largest |log return| (earliest on tie; skip NaN); direction = "down" for trigger drawdown, "up" for rally, else sign of the anchor-day log return ("down" if < 0); move_pct = min drawdown Leg.move for drawdown trigger, max rally Leg.move for rally trigger, else close[end_pos]/close[max(start_pos-1, 0)] - 1; max_z = nanmax |z| over [start_pos, end_pos] (0.0 if all NaN); severity = max_z + abs(move_pct) / settings.severity_move_step (continuous — Claude's discretion, documented in docstring); search window: for shock/gap triggers positions [start_pos - search_pre_days, end_pos + search_post_days], for drawdown/rally triggers a window of 2*structural_search_half_width+1 trading days centred on the steepest day (most negative log return in the cluster for drawdown, most positive for rally) per docs/SPEC.md "5 trading days around the steepest leg"; clamp all positions to [0, len-1]; recovery_date = latest recovery_pos among the cluster's drawdown legs as a date, NaT if none or any is None; episode_id = f"{anchor_date:%Y-%m-%d}_{trigger}"; detector_version = settings.detector_version. Raise ValueError if episode_ids collide (should be impossible because clusters are disjoint). Return rows sorted by start_date with EPISODE_COLUMNS order. No try/except. No numeric literals in function bodies other than 0 and 1.
